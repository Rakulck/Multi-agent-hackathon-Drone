# Drone Fleet Intelligence — Starter Pack

This pack defines the project before implementation begins. It is intentionally centered on a company-operated, heterogeneous drone fleet—not a consumer marketplace.

## Start in this order

1. Read `PROJECT_IDEA.md` and `GOALS_AND_SCOPE.md`.
2. Give `CURSOR_BASE_SETUP_PROMPT.md` to Cursor before the hackathon if pre-event scaffolding is allowed.
3. Confirm the environment using `ENVIRONMENT_AND_PACKAGES.md` and `.env.example`.
4. At the hackathon, use `CURSOR_3D_SIMULATION_PROMPT.md` for the core demo.
5. Use the remaining segment documents as acceptance criteria.
6. Use `references/` when connecting each external service.

## Locked positioning

**Different drones. One shared intelligence layer.**

We give commercial drone fleets a shared operational brain, so every drone learns from missions that came before it.

## Important boundary

This prototype is a business-level orchestration and simulation layer. It does not claim to replace certified autopilots, detect-and-avoid hardware, UTM/LAANC systems, regulatory approval, or a human safety operator.
